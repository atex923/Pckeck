# Pckeck V0.2.2

PDF 文件內容比對工具。以 Pcheck V0.2.1 為基準，保留雙列工具列、同步頁面錨點與 `.fck` 自足式比對庫。

## 新功能

- 左欄新增「不同處頁碼」，列出每筆差異的舊檔頁、新檔頁、差異類型及標線數。
- 雙擊差異列可讓左右 PDF 同時跳至對應頁面。
- 左欄保留原有「篇章節」分頁。
- 新增、刪除及修改內容會分別顯示；單側沒有對應頁時顯示 `-`。

## 執行

1. 安裝 Python 3.11 以上版本。
2. 執行 `python -m pip install -r requirements.txt`。
3. 雙擊 `啟動程式.bat`，或執行 `python Pckeck_V0.2.2.pyw`。

程式執行需要同層的 `runtime/` 資料夾，搬移時請保留完整轉移包結構。
