# Pckeck V0.2.3

PDF 文件內容比對工具。保留雙列工具列、同步頁面錨點、差異頁碼導覽與 `.fck` 自足式比對庫。

## 自訂標記

- 「螢光筆」與「雙刪除線」模式可在左、右 PDF 頁面上拖曳標記。
- 顏色可由色彩選擇器自訂，粗細可設定為 0.5～40 pt。
- 左、右頁面可分別復原最後一筆或清除全部自訂標記。
- 自訂標記會保存進 `.fck`，並與自動差異線一起輸出到標記 PDF。

## 差異導覽

- 左欄新增「不同處頁碼」，列出每筆差異的舊檔頁、新檔頁、差異類型及標線數。
- 雙擊差異列可讓左右 PDF 同時跳至對應頁面。
- 左欄保留原有「篇章節」分頁。
- 新增、刪除及修改內容會分別顯示；單側沒有對應頁時顯示 `-`。

## 執行

1. 安裝 Python 3.11 以上版本。
2. 執行 `python -m pip install -r requirements.txt`。
3. 雙擊 `啟動程式.bat`，或執行 `python Pckeck_V0.2.3.pyw`。

程式執行需要同層的 `runtime/` 資料夾，搬移時請保留完整轉移包結構。
