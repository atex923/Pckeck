# Pcheck V0.2.0 - 比對庫

## PCdb.fck 保存內容

`PCdb.fck` 是 SQLite 格式的自足式比對庫，會保存：

- 左側舊 PDF 與右側新 PDF 的完整檔案內容及 SHA-256 校驗值
- 已完成分析的紅／藍標線、章節對應與統計
- 自設同步頁面錨點
- 左右縮放倍率及目前捲動位置
- 同步捲動與 OCR 開關
- 視窗大小、資料格式版號及儲存時間

因此原始 PDF 被移動後，比對庫仍可獨立開啟並繼續工作。

## 操作

- `Ctrl+O`／「開啟比對庫」：開啟 `.fck` 並立即還原工作。
- `Ctrl+S`／「儲存比對庫」：儲存到目前比對庫；第一次使用會進入另存。
- `Ctrl+Shift+S`／「比對庫另存」：另存新的 `.fck`，預設檔名為 `PCdb.fck`。
- 已開啟或儲存過比對庫時，關閉程式會自動保存目前狀態。
- 尚未建立比對庫而直接關閉時，程式會詢問是否先儲存。

`.fck` 包含原始 PDF，因此檔案大小至少約等於兩份 PDF 的總和。
