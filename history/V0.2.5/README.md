# Pckeck V0.2.5

PDF 文件內容比對工具。保留雙列工具列、同步頁面錨點、差異頁碼導覽與 `.fck` 自足式比對庫。

## 左右獨立標記工具列

- 左、右 PDF 瀏覽區上方各有自己的「瀏覽、螢光筆、雙刪除線」工具列。
- 左右螢光筆分別設定顏色與 0.5～40 pt 粗細，切換另一側作筆記時不會互相覆蓋。
- 雙刪除線顏色由左右共用；在線任一側選色，另一側會同步更新。
- 雙刪除線粗細固定為 4 pt，不提供調整控制。
- 左右可各自復原或清除標記；右側工具列可直接匯出疊圖標記資料。

## 右欄標記資料

- 「匯出右欄標記資料」會建立 UTF-8 JSON，副檔名預設為 `.pcheckmarks.json`。
- 資料包含右側 PDF 的 SHA-256、頁面尺寸、自動差異線及右側手動標記。
- 所有座標、顏色、粗細與透明度均會保留，可供 PDF 找碴程式進行疊圖檢查。
- 完整欄位與繪製規則請見 `MARK_DATA_FORMAT.md`。

## 自訂標記

- 「螢光筆」與「雙刪除線」模式可在左、右 PDF 頁面上拖曳標記。
- 顏色可由色彩選擇器自訂，粗細可設定為 0.5～40 pt。
- 左、右頁面可分別復原最後一筆或清除全部自訂標記。
- 自訂標記會保存進 `.fck`，並與自動差異線一起輸出到標記 PDF。

## 差異導覽

- 左欄新增「不同處頁碼」，列出每筆差異的舊檔頁、新檔頁、差異類型及標線數。
- 雙擊差異列可讓左右 PDF 同時跳至對應頁面。
- 左欄保留原有「篇章節」分頁。
- 新增、刪除及修改內容會分別顯示；單側沒有對應頁時顯示 `-`。

## 執行

1. 安裝 Python 3.11 以上版本。
2. 執行 `python -m pip install -r requirements.txt`。
3. 雙擊 `啟動程式.bat`，或執行 `python Pckeck_V0.2.5.py`。

程式執行需要同層的 `runtime/` 資料夾，搬移時請保留完整轉移包結構。

`Pckeck_V0.2.5.py` 與 `Pckeck_V0.2.5.pyw` 內容相同；`.pyw` 適合 Windows 無主控台啟動，`.py` 適合命令列執行與除錯。
